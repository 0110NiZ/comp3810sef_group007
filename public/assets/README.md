# Decorative artwork

`cottage.svg` and `companions.svg` are original, project-local SVG drawings made
for Animal Rescue Center. They use a small grid and crisp edges for a pixel-inspired look.
They contain no external images, fonts, scripts or third-party game artwork.
No external asset packs or third-party licenses are used.

Both assets are decorative: the templates use empty alt text and aria-hidden.

The shared `public/icons.svg` library is original pixel SVG artwork on a 16×16 grid. `landscape.svg` combines the original cottage and companions. No external asset packs, fonts or licenses are required.
